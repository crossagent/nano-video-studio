# 工作流：3D 白模分镜动画预演（Previs Video）

## 执行步骤
1. **场景空间体量构建**：
   - 贝卡·罗暴风麦原与履带联合收割机
   - 自由避难所八角防线与旋转雷达导弹防御塔
   - 布伦兄妹预制板房内景（工作台、地震仪、升降百叶窗）
   - 萨尔那加出土金字塔裂谷（60米神庙、外星结晶大门、400米通天纯能信标）
   - 查尔星火山熔岩与异虫几丁质主巢尖塔
2. **多机位时间轴绑定（Camera Timeline Markers）**：
   - 使用 Blender 5.x Timeline Markers 将 10 组机位按时间顺序精确绑定至指定帧范围（1~792 帧）；
   - 在各时间段注入运镜动效（手持晃荡、跟跑平移、俯冲航拍、仰天直冲）与主体位移动态。
3. **分镜工程存储**：
   - 将完整包含几何体、材质与时间轴动画的 `.blend` 文件保存至 `work/previs_act01_video.blend`。
4. **视频渲染与编码**：
   - 使用 Workbench 引擎快速渲染 2.39:1（1920x804）宽银幕帧序列；
   - 自动通过 OpenCV 将帧序列封装合成为 24fps 的 `output/previs_act01_animatic.mp4` 视频文件；
   - 自动清理临时单帧缓存，确保工作区整洁。
5. **人机协同评审**：
   - 成果保留在任务目录，状态标记为 `review`，等待人类导演确认后再行归档至 `assets/storyboards/`。
