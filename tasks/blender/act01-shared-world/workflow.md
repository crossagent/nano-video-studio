# 工作流程

基于原 10 镜头白模工程制作独立副本。麦原保留原点，避难所向麦原东侧衔接，板房安置在避难所内，神庙裂谷继续位于东侧。场景使用集合和空间锚点分区，相关摄像机随场景锚点一起移动；查尔星保留独立布景。车内机位绑定收割机主体，以便随车辆运动。保留原时间轴相机标记和镜头时长。

通过 `platform/blender/run.cmd` 执行任务脚本，保存 `.blend`，导出抽帧和连续 H.264 预演视频供审查。

预演先以 Blender 渲染 PNG 序列，再用任务目录内 imageio-ffmpeg 的 FFmpeg 编码为 H.264；当前 Blender 构建没有提供内置 FFmpeg 输出。当前只建立粗略地面连接，没有制作车辆从麦原驶入聚居地的连续路线。

相机修复版由 fix_camera_motion.py 对原共享场景副本调整：修正驾驶舱相机旋转曲线的角度跨界，重设查尔星相机与人物站位，再渲染 PNG 序列并编码 camera_fix 视频。
