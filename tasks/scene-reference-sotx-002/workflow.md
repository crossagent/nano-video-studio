# 实际生成流程

使用内置 image_gen 生图工具，每场景单独调用；未调用旧任务写的 Nano Banana 2.1，也未使用 ComfyUI 生图。实际模型版本、seed、采样参数未由工具公开，不作推测。工具原始结果保留在 generated_images，复制至本任务。

初版完整提示词见 prompts-v1.json。初版请求 16:9，2048×1152（若支持）；实际尺寸以文件检查为准。

收到用户反馈后，以查找的 StarCraft II 导弹塔图作几何参考重做场景02，同时调整整套低对比度、柔和高光和哑光材质。参考来源：https://www.pinterest.com/pin/sc2-terran-missile-turret-by-phillgonzodeviantartcom-on-deviantart--497084877592848783/ ，参考图片署名 Blizzard Entertainment 2010 / PhillGonzo，作为外观参照，不作为正式原创资产。
