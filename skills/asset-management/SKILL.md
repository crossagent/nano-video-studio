# 资产管理

读取工程根目录 README.md，按产物类型选择 assets 子目录，不创建编号阶段目录。

资产说明记录用途、版本、来源任务及关联资产。设定集使用 Markdown 组织设计说明与图片索引，角色保留视觉锚点，场景保留空间与光影基准。分镜记录镜头 ID、时长、景别、运动、画面及引用资产。

草稿与候选产物保存在 tasks。按已有授权和任务验收标准选用结果后，复制到对应资产目录，并记录验收结论和来源。修改资产时保留被引用版本，标记受影响任务需复核。

资产之间的关系由实际引用决定，不预设创作先后。
