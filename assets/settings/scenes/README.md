## 视觉统一规范 (Cinematographic Standards)
1. **摄影机规范**：全套场景均采用 16:9（或 2.39:1 变形宽银幕画幅），Arri Alexa 65 / Panavision 变形镜头质感，真实电影景深与颗粒感。
2. **材质写实度**：
   - **人类文明**：粗粝的工业锈蚀、泥浆飞溅、氧化划痕、剥落车漆与实体螺栓（脏科幻工业美学）；
   - **异虫文明**：黏液分泌、生物脉动、角质纤维与高热熔岩反射（写实生物恐怖美学）；
   - **星灵文明**：光滑无缝的金属冷锻压、超导悬浮、纯净晶体漫射（高等神圣科技美学）；
   - **萨尔那加**：超脱三族的深黑吸光合金、虹彩能量符文、超越凡人理解的宏大几何体（远古造物主神性美学）。
3. **出图管理**：所有场景图均需保持无遮挡、无水印、无非画面人工框线的原画级质量，并归档至 `assets/settings/scenes/`。
