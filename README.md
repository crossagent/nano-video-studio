# nano-video-studio

工程按资产与任务管理。影视创作由不同工种协作完成，不设置编号阶段或固定顺序。

## 目录结构

- `novels/`：原著小说资源与参考文件。
- `assets/scripts/`：故事大纲、分场大纲、标准电影文学剧本。
- `assets/settings/style/`：影视美术风格与视觉规范。
- `assets/settings/characters/`（与 `设定/角色设定` 互通）：核心角色设定集与设计图。
- `assets/settings/scenes/`（与 `设定/场景设定` 互通）：场景设定集、空间与光影基准。
- `assets/storyboards/`：逐镜分镜脚本、分镜图、Blender 3D 预演工程与视口渲染。
- `assets/clips/`：正式采用的动态与视频片段。
- `assets/audio/`：配音、配乐、音效素材。
- `tasks/<task-id>/`：具体工作的要求、流程、执行记录与过程产物。
- `.agents/skills/`：资产管理、任务管理及各专业工种技能库。

## 资产管理规范

资产是正式采用的产物，按类型统一存放在 `assets/` 相应子目录下。
每项资产均配有说明文档（同名 `.md` 或专用规格），记录用途、版本、来源任务及关联资产：
- 角色设定保留视觉锚点、服装细节与色板 Hex；
- 场景设定保留空间关系、摄影构图与光影基准；
- 分镜记录镜号 ID、时长、景别、运动、画面及 3D Previs 调度。

草稿、过程文件与候选导出保留在对应 `tasks/<task-id>/` 目录内，验收通过后再归档至 `assets/`。

## 任务执行规范

每项工作使用独立目录 `tasks/<task-id>/`：
- `task.md`：任务目标、要求、输入资产路径及版本、验收标准与依赖。
- `workflow.md`：本任务的执行步骤、工具、参数或预演方案。
- `log.md`：执行过程记录、重试日志、评审结论与资产去向。
- `inputs/`：任务专用参考。
- `work/`：工程文件、草稿与中间文件。
- `output/`：生成结果与候选导出。

## 专业工种协同

故事创作、编剧、美术风格、角色设计、场景设计、分镜（含 3D 预演）作为核心工种，均可独立接单、并行工作并双向迭代。
