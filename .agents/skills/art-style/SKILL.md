# 美术风格

## 产物与用途

视觉规范、色板与风格样张，供角色、场景和镜头统一视觉语言。

## 输入与依赖

读取项目根目录 README.md、任务要求和实际需要的输入资产及版本。缺失内容记入任务，可用输入支持的工作继续推进，不要求其他工种整体先完成。任务记录遵循 [任务管理](../task-management/SKILL.md)，交付遵循 [资产管理](../asset-management/SKILL.md)。

## 生产软件

Markdown 编辑器；ComfyUI Desktop 制作样张，按需使用可用绘画软件修图。

使用 ComfyUI 时读取项目根目录 platform/comfyui/README.md，复用现有桌面实例与平台客户端，记录实际软件版本、工作流、模型、提示词、seed 和参数。

## 制作流程

1. 提炼题材、时代与参考用途
2. 定义造型、材质、色彩、光影和摄影基准
3. 制作色板与样张
4. 核对规范与样张一致并修订。

## 格式与验收

Markdown 说明、Hex 色板、PNG 样张；外部参考可保留 JPEG/WebP。记录图片尺寸、色彩空间及来源。

核对任务验收标准、引用路径与文件可读性，说明未解决的问题。

## 存放与归档

以下路径相对项目根目录。要求、流程和执行记录写入 tasks/<task-id>/ 的 task.md、workflow.md、log.md；参考放 inputs/，草稿和可编辑源文件放 work/，候选导出放 output/。

按已有授权和验收标准正式采用后，将交付文件及说明复制到 assets/settings/style/，记录用途、版本、来源任务和关联资产，保留任务原始结果。
