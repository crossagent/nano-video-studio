# 编剧

## 产物与用途

分场大纲和电影文学剧本，供分镜、表演及声音制作使用。

## 输入与依赖

读取项目根目录 README.md、任务要求和实际需要的输入资产及版本。缺失内容记入任务，可用输入支持的工作继续推进，不要求其他工种整体先完成。任务记录遵循 [任务管理](../task-management/SKILL.md)，交付遵循 [资产管理](../asset-management/SKILL.md)。

## 生产软件

Markdown 文本编辑器；按任务要求使用可用文档或剧本排版软件导出，保留 Markdown 主稿。

## 制作流程

1. 读取故事大纲与人物场景设定
2. 拆分场次并分配稳定场景 ID
3. 编写可视动作、对白、旁白及必要声音提示
4. 检查情节衔接、人物语气和预计时长，修订并记录版本。

## 格式与验收

UTF-8 Markdown；场次标题含 ID、内外景、地点与时间；动作、角色名、对白和旁白分段标识；时长注明单位。PDF/DOCX 等按任务要求额外交付。

核对任务验收标准、引用路径与文件可读性，说明未解决的问题。

## 存放与归档

以下路径相对项目根目录。要求、流程和执行记录写入 tasks/<task-id>/ 的 task.md、workflow.md、log.md；参考放 inputs/，草稿和可编辑源文件放 work/，候选导出放 output/。

按已有授权和验收标准正式采用后，将交付文件及说明复制到 assets/scripts/，记录用途、版本、来源任务和关联资产，保留任务原始结果。
