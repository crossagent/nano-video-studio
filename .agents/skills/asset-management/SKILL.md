# 资产管理

## 产物与用途

产物是正式资产文件、配套说明及必要索引，用于检索、引用、版本追溯和后续制作复用。

## 输入与依赖

读取项目根目录 README.md、来源任务档案、候选交付物与验收结论。按专业 skill 核对文件规格，不预设创作先后顺序。

## 生产软件

使用 Markdown 编辑器编写说明，文件系统工具复制文件；使用产物对应软件打开验证，必要时用媒体检查工具读取尺寸、帧率、编码和时长。结构化索引使用 JSON。

## 制作流程

1. 核对候选文件、用途、来源任务、输入版本、可编辑工程和验收记录。
2. 按已有授权和任务验收标准确定正式采用版本；存在明确人工验收要求时取得相应结论后再入库。
3. 按产物类型复制文件并编写同名说明或专用规格，记录用途、版本、来源任务、关联资产、软件及必要参数。
4. 在目标目录验证文件可打开、引用可解析、工程依赖完整；更新来源任务的资产去向。
5. 修改时保留被引用版本，记录替代关系和受影响任务的复核事项。

## 格式与验收

说明使用 UTF-8 Markdown，结构化索引使用有效 JSON；创作文件遵循对应专业 skill，不通过改扩展名转换格式。角色说明保留视觉锚点、服装细节与 Hex 色板；场景说明保留空间、摄影和光影基准；分镜说明记录镜头 ID、时长、景别、运动、构图、引用资产和工程文件。确认版本和来源可追溯。

## 存放与归档

路径相对项目根目录：故事和剧本放 assets/scripts/；美术规范放 assets/settings/style/；角色放 assets/settings/characters/；场景放 assets/settings/scenes/；分镜与预演放 assets/storyboards/；正式动态片段放 assets/clips/；配音、配乐与音效放 assets/audio/。说明与对应文件同目录，不创建编号阶段目录。

草稿与候选产物保留在来源 tasks/ 目录，入库使用复制方式。任务档案本身不转移到 assets/。
